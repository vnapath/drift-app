# Roadmap

## Milestone 1: Auth and Sending

- Configure auth infrastructure.
- Build login and signup UI.
- Create profile setup.
- Show authenticated Home state.
- Save a text Drift to Supabase.

## Milestone 2: Receiving and Matching

- Receive a random available Drift.
- Keep or pass an incoming Drift.
- Create a match when a Drift is kept.
- Enable real-time chat for matches.

## Later

- Safety reporting flow.
- Push notifications.
- Image or voice Drifts.
- Moderation tools.
- Premium or discovery features.
